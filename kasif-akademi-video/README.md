# Kaşif Akademi – dikey tanıtım videosu

`kasif-akademi-tanitim.mp4`: 1080×1920, 30 fps, 29 sn (Reels / Hikâye / WhatsApp durum için).

- `index.html` animasyonun kendisi; tarayıcıda açınca önizleme olarak döngüde oynar.
- `render.mjs` sayfayı kare kare yakalayıp MP4 üretir: `node render.mjs`
- Yazı, telefon ya da adres değişecekse `index.html` içinde düzeltip komutu yeniden çalıştırmak yeterli.
- Öğrenci görseli (`assets/ogrenci.jpg`) özgün afişten kırpıldı.
